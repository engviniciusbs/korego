# Tela "Conexões" — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (escolhido) para implementar tarefa a tarefa.

**Goal:** Trocar a tela "Tokens de API" pela tela "Conexões": cartões por cliente com logo oficial e uma ação principal, e a lista "Agentes conectados".

**Architecture:** O modelo de dados dos clientes fica em `web/src/lib/mcp-clients.ts`, com dois construtores: OAuth (só a URL) e token (com cabeçalho). Os componentes visuais ficam em `web/src/components/connections/`. A página passa a `/configuracoes/conexoes/`, e a rota antiga redireciona.

**Tech Stack:** Next.js (export estático), Tailwind v4 com os tokens de `globals.css`, Vitest e Testing Library.

**Spec:** `docs/superpowers/specs/2026-11-14-conexoes-design.md`. O visual de referência é o mockup `conexoes-v3.html` (em `.superpowers/brainstorm/`).

## Global Constraints
- Sem cantos arredondados, só tokens do tema (`bg-surface`, `border-line`, `text-fg-muted`, `bg-accent`…), fonte mono nos rótulos em caixa alta.
- SVGs dos logos embutidos (CSP `'self'`). Fontes: Simple Icons 16.37.0 (claude, cursor, googlegemini, windsurf), Simple Icons 15.0.0 (openai) e @vscode/codicons 0.0.36 (vscode).
- Cores dos logos:
  - Claude `#D97757`;
  - Gemini `#8E75B2`;
  - VS Code `#3ea6f2`;
  - Cursor, OpenAI e Windsurf em `currentColor` (claro).
- URL `https://<domínio>/mcp`; nome do servidor `korego`.
- Comandos OAuth:
  - Claude Code: `claude mcp add --transport http -s user korego <url>`;
  - Codex: `codex mcp add korego --url <url>` e, na linha seguinte, `codex mcp login korego`;
  - Gemini: `gemini mcp add --scope user --transport http korego <url>`.
- Textos pt-BR iguais ao mockup.
- Margem lateral de 16px no celular; a grade tem 3 colunas a partir de `lg`, 2 a partir de `sm` e 1 abaixo disso.

## Review Focus
1. A versão OAuth não pode conter `Authorization` nem `Bearer` em nenhum texto ou link.
2. Na versão com token, o token aparece em todos os links e trechos, e o Cursor e o VS Code recebem os cabeçalhos no link.
3. A rota antiga `/configuracoes/tokens/` precisa redirecionar, sem página em branco.
4. Painel sem domínio HTTPS: aparece o aviso com o link para Configurações → Painel, sem cartões quebrados.
5. Comandos longos quebram linha no celular, sem rolagem horizontal da página.

### Task 1: Modelo dos clientes
**Files:** Modify `web/src/lib/mcp-clients.ts` and `web/src/lib/__tests__/mcp-clients.test.ts`.
- Produces:
  - `type AgentAction = {type:"link"; href:string; label:string} | {type:"command"; text:string} | {type:"config"; text:string; label:string}`.
  - `interface AgentClient {id: McpClientId (sem "outro"); name; kind:"Editor"|"Terminal"; action: AgentAction; note: string; manual?: {label:string; text:string}}`.
  - `oauthAgentClients(origin): AgentClient[]` e `tokenAgentClients(origin, token): AgentClient[]`, na ordem cursor, vscode, claude-code, codex, gemini, windsurf.
  - `mcpAddCommand` permanece.
- OAuth:
  - Cursor: link `Adicionar ao Cursor`, config `{url}`; manual: o JSON do `~/.cursor/mcp.json`.
  - VS Code: link `Adicionar ao VS Code`; manual: `code --add-mcp …`.
  - Claude, Codex e Gemini: command, com os textos acima.
  - Windsurf: config `Copiar configuração` com `serverUrl`.
  - Notas iguais ao mockup.
- Token:
  - os mesmos clientes, com `Authorization: Bearer <token>`;
  - Claude: `mcpAddCommand` com `-s user`;
  - Codex: config TOML com `http_headers`, label `Copiar configuração`, nota "Cole em ~/.codex/config.toml.";
  - Gemini: config `settings.json` com `httpUrl` e `headers`, nota "Cole em ~/.gemini/settings.json.";
  - Cursor e VS Code: links com `headers`.
- Tests:
  - OAuth sem Bearer/Authorization (Review Focus 1);
  - token presente em cada ação e manual (Review Focus 2);
  - JSON decodificado do link do Cursor e do VS Code;
  - texto exato do Claude Code e do Codex.

### Task 2: Logos e componentes visuais
**Files:** Create `web/src/components/connections/client-logo.tsx`, `web/src/components/connections/agent-grid.tsx` and `web/src/components/connections/__tests__/agent-grid.test.tsx`.
- `ClientLogo({id})` renders an inline SVG with `aria-hidden` inside a 36px box with a border.
- `CopyButton({text, label, children?})` is moved out of the page into this module and exported.
- `AgentGrid({clients})`:
  - uma grade de cartões separados por linha de 1px (`gap-px bg-line`);
  - cada cartão tem logo, nome, tipo (mono e caixa alta), a ação, a nota e um `<details>` "Configuração manual" quando `manual` existir;
  - o link é um `<a>` primário em largura total, com o ícone de "abrir externo";
  - o comando aparece num bloco `code` com o botão Copiar colado à direita;
  - a config é um botão secundário que copia.
- Tests:
  - renders 6 cards with name and kind;
  - the link has the right `href`;
  - Copiar calls `navigator.clipboard.writeText` with the command;
  - `details` only appears when `manual` is set.
